## Test Strategy

Each test:
1. Creates an instance of the response type with `scope` set to `"user"` (or `User` enum variant)
2. Verifies the scope field exists and has the correct value
3. Serializes to JSON and verifies the JSON contains `"scope":"user"`

This ensures both:
- **Compile-time safety**: The scope field exists in the struct
- **Runtime correctness**: The scope field serializes to the expected value
