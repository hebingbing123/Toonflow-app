## Files Modified

### 1. `backend/src/assets/crud/create.rs`
**Changes:**
- Added import: `use crate::error::helpers::conflict_i18n;`
- Migrated duplicate asset name conflict error from manual `ApiError::Conflict` with `current_locale()` to `conflict_i18n()` helper

**Before:**
```rust
return Err(ApiError::Conflict(
    match crate::error::locale::current_locale() {
        crate::error::ApiLocale::En => {
            "an asset with this name already exists in the project".into()
        }
        crate::error::ApiLocale::Zh => "项目中已存在同名资产".into(),
    },
));
```

**After:**
```rust
return Err(conflict_i18n(
    "an asset with this name already exists in the project",
    "项目中已存在同名资产",
));
```

### 2. `backend/src/assets/crud/patch_delete/patch/inner.rs`
**Changes:**
- Added import: `use crate::error::helpers::conflict_i18n;`
- Migrated asset name clash conflict error from manual `ApiError::Conflict` with `current_locale()` to `conflict_i18n()` helper

**Before:**
```rust
return Err(ApiError::Conflict(
    match crate::error::locale::current_locale() {
        crate::error::ApiLocale::En => {
            "another asset in this project already uses that name".into()
        }
        crate::error::ApiLocale::Zh => "项目中已有其他资产使用该名称".into(),
    },
));
```

**After:**
```rust
return Err(conflict_i18n(
    "another asset in this project already uses that name",
    "项目中已有其他资产使用该名称",
));
```

## Migration Pattern Consistency

This migration follows the established pattern from previous modules (settings, workspaces, projects):
1. Import the appropriate helper function from `crate::error::helpers`
2. Replace manual `ApiError::Conflict(match current_locale() { ... })` with `conflict_i18n(en_msg, zh_msg)`
3. Simplify code by removing the match expression
4. Maintain exact same English and Chinese messages
