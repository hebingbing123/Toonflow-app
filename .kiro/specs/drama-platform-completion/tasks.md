# 实现计划：drama-platform-completion

## 概述

本计划把 `requirements.md` 与 `design.md` 中的能力拆成可逐步执行的任务。顺序遵循：

1. 先补 P0 功能闭环
2. 再补 P1 流程治理
3. 最后补 P2 质量与成本优化

当前任务状态默认均未开始。

## 备注

- 本任务清单默认按功能优先顺序推进，不要求一次性全量实现。
- 记忆预算、ROI、观察笔记治理被视为本 spec 的正式主线，不再作为“后续有空再看”的附加项。
- 在当前阶段，建议每次修改仅测试对应变更范围；全量门禁留到整轮优化接近完成时统一执行。
- 属性测试注释格式统一为：

```rust

```
