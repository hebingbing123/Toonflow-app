# short-video-space 优化 V2 Spec（运营闭环 + 可观测 + 性能 + 治理）

## 目标

在不突破需求 8.2（不做专业 NLE）的前提下，补齐 short-video-space 的第二阶段能力：

- 从“可用”提升到“可运营、可度量、可回归、可扩展”
- 从“单次操作闭环”提升到“持续优化闭环”
- 从“功能完成”提升到“产品稳定性与长期维护能力”

## 范围边界

- **In scope**：发布运营闭环、任务与数据治理、性能与可观测、测试与契约治理、权限细化。
- **Out of scope**：电影级多轨编辑、复杂特效时间线、专业调色/混音工作台。

---

## V2 工作流补强

### V2-1 发布运营闭环

#### 任务

1. 平台差异化低表现阈值（按平台/项目可配置）
2. 发布时间窗口推荐（按历史表现段位建议）
3. 文案 A/B 试验（至少 title/description 两维）
4. 预警后自动生成改写任务与重投建议

#### 验收标准

- 预警规则不再是全平台同阈值，支持平台级覆盖。
- UI 可展示“推荐窗口 + 依据摘要（历史样本）”。
- A/B 试验结果可回看（曝光、互动、转化 proxy）。
- 命中低表现预警后，任务中心可直接看到“改写/重投”任务并回链原 job。

---

### V2-2 多草稿与批量发布体验

#### 任务

1. 发布面板新增草稿选择器（不再默认 first draft）
2. 草稿级批量操作（定时、清档、重排）
3. 批量发布预检查汇总（按草稿聚合阻塞）

#### 验收标准

- 任意项目下可显式切换操作目标草稿。
- 批量发布时能看到“可执行/阻塞”分组与原因。
- 不会因单草稿异常导致全批次不可操作。

---

### V2-3 时间线效率与恢复能力

#### 任务

1. 批量时长对齐（按脚本/选中镜头）
2. 批量启停与批量替换当前版本
3. 操作草稿与提交两段式（预览 diff -> 确认写回）
4. 失败后一键重试最近动作（action replay）

#### 验收标准

- 批量动作支持最小粒度选择（脚本级、镜头级）。
- 二段式提交前可看到本次变更摘要（数量、范围、字段）。
- 网络抖动失败时可“一键重放”且不重复破坏状态。

---

### V2-4 可观测性与运营仪表盘

#### 任务

1. 关键操作埋点（刷新、发布、重排、导出检查、设当前、预警处理）
2. 前端错误标准化上报（status/message/code/request-id）
3. 核心漏斗看板（从候选 -> 成片 -> 发布 -> 预警 -> 回改）
4. 延迟与失败率 SLI（P50/P95、失败码分布）

#### 验收标准

- 每个关键动作可追踪成功率、耗时分布与常见失败原因。
- 面向产品/运营可查看周维度转化漏斗与问题热区。
- 工程侧能按 request-id 快速回溯单次失败链路。

---

### V2-5 性能与并发稳定性

#### 任务

1. overview 分片拉取 + 局部刷新（避免全量重拉）
2. 请求代际保护统一封装（防旧请求覆盖新数据）
3. 大项目分页/“查看更多”策略（脚本、镜头、作业）
4. 发布与候选拉取并发限流

#### 验收标准

- 高频操作后仅刷新受影响卡片，不触发全页闪动。
- 并发刷新下不出现 UI 回退。
- 大项目（>1k job / >300 shots）仍可稳定浏览。

---

### V2-6 契约与测试治理

#### 任务

1. OpenAPI 变更自动对比（PR gate）
2. rust_api 与 OpenAPI 一致性检查（关键路径）
3. 并发冲突 E2E（重排冲突、版本冲突、回滚）
4. 跨面板一致性测试（assembly/compare/export-check 同快照）
5. 发布矩阵回归测试（9 平台能力状态 + delivery_mode）

#### 验收标准

- 契约漂移在 CI 中可被阻断。
- 冲突类缺陷在自动化测试中可稳定复现并验证修复。
- 跨面板一致性有自动化覆盖，不依赖人工眼测。

---

### V2-7 权限与数据治理

#### 任务

1. 发布相关细粒度权限（read/publish/retry/cancel/audit）
2. performance snapshot 归档与保留策略
3. 审计数据可筛选导出（按 delivery_mode / 平台 / 项目 / 时间）

#### 验收标准

- 最小权限原则落地，敏感操作可控。
- 长周期项目不会因快照无上限增长导致查询退化。
- 审计报表可满足运营复盘与合规追溯。

---

## 里程碑建议

- **Milestone V2-A（运营闭环）**：V2-1 + V2-2
- **Milestone V2-B（稳定性与性能）**：V2-3 + V2-5
- **Milestone V2-C（治理）**：V2-4 + V2-6 + V2-7

## 成功指标（建议）

- 发布后 7 日内：
  - 低表现预警后的改写/重投转化率提升
  - 关键操作失败率下降（至少 30%）
  - P95 刷新耗时下降（至少 25%）
  - 线上“状态不一致/回退”类反馈显著下降
