快速上手

三步开始使用 OpenFlow

选择适合你的路径：下载桌面版、运行 Web 客户端，或从源码搭建开发环境。

① 下载客户端

在 GitHub Releases 获取 macOS / Windows / Linux 构建包，安装后配置 API 地址即可登录。

前往下载

② 本地开发环境

克隆仓库后启动 Supabase 与 Rust 后端（默认 8666），再运行 Flutter 前端连接 API_BASE_URL。

开发者指南

③ Web 版访问

构建 Flutter Web 并部署到静态托管；在 website/js/config.js 填写 appUrl 后，本站「登录」将直达你的应用。
