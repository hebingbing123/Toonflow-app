创作者

下载客户端 · 约 10 分钟

  1. 在 GitHub Releases 下载 macOS / Windows / Linux 安装包（或从源码自行构建 Flutter 桌面版）。
  2. 准备可访问的 OpenFlow API 地址（团队内网地址或你自建的 https://api.example.com）。
  3. 首次启动时在设置中填写 API Base URL，使用 Supabase 账号登录（与后端同一 Auth 项目）。
  4. 创建项目 → 进入工作室 → 从「剧本」步开始：导入网文或一句话生成剧本，再进入分镜与素材任务。

开发者

本地开发环境 · 约 30–60 分钟

前置：Rust stable、Flutter 3.10+、Docker、Supabase CLI、Node 18+ / Yarn（跑门禁脚本）。

  1. 克隆仓库并进入项目根目录。
git clone https://github.com/HBAI-Ltd/Openflow-app.git
cd Openflow-app
  1. 启动本地数据库（PostgreSQL + Auth）。
supabase start
supabase status   # 记下 DATABASE_URL、JWT secret
  1. 配置并启动 Rust 后端（默认监听 8666）。
cd backend
cp .env.example .env   # 填入 DATABASE_URL 等
cargo run --bin openflow-server
  1. 另开终端启动 Flutter（Web 或桌面）。
cd frontend
flutter pub get
flutter run -d chrome --dart-define-from-file=dart_defines.dev.json
  1. 浏览器打开 http://127.0.0.1:8666/api/v1/docs 查看 OpenAPI；宣传页即 http://127.0.0.1:8666/。

运维

私有化 / 生产部署要点

  1. 生产数据库使用 Supabase 云端或自建 PostgreSQL，执行 supabase/migrations/ 迁移。
  2. 以 release 模式构建 openflow-server，配置 DATABASE_URL、JWT、对象存储与 LLM 密钥（仅服务端）。
  3. 反向代理终止 TLS，暴露 /api/v1 与 WebSocket /api/v1/ws；静态 Flutter Web 可放 CDN 或同域。
  4. 启用 OpenTelemetry / 任务队列监控；计费 Webhook 按环境配置 Stripe / Alipay / Paddle。
  5. 危险操作（清库等）走受控 CLI，生产 HTTP 清库接口保持 501 设计。
运维快速开始 按角色索引

如何确认已经跑通？

  • GET /api/v1/health 或 Swagger 页面可打开且无 5xx。
  • Flutter 客户端能登录并看到「项目」首页与流水线导航。
  • 创建测试项目后，剧本步可触发 AI 任务（需配置 LLM Key）。
  • 任务中心可见队列状态，WebSocket 能收到任务进度推送。

Web 版：构建 Flutter Web 后，在 website/js/config.js 设置 appUrl，本站「登录」将跳转到你的应用。
