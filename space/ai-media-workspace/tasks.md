# 任务文档：AI Media Workspace

## 概述

本任务清单按 **桌面主生产、Web / 手机协作、Rust Core 统一** 的方向拆分，默认与以下现有 spec 联动推进：

- `harness-rust-flutter`
- `short-video`
- `short-video-light-editing-spec`
- `moneyprinter-short-video-space`

目标不是新起一条平行产品线，而是把现有短视频、资产、任务、工作台能力，收束成一个更完整的 AI 媒体空间。

## A. Space 基线与术语收口

- [ ] A1. 建立 `AI Media Workspace` 的正式产品名、导航名和文档入口
- [ ] A2. 明确 `desktop production`、`web collaboration`、`mobile collaboration` 三种运行语义
- [ ] A3. 将该 Space 与已有 `short-video` Space 的边界写清楚：前者是上层媒体空间，后者是垂直短视频链路
- [ ] A4. 统一文档中的“轻量编辑 / 粗剪 / 重型剪辑 / 协作入口”术语

## B. 共享项目与资产模型

- [ ] B1. 盘点现有项目、脚本、分镜、资产、任务模型中哪些字段已可复用
- [ ] B2. 定义图片编辑文档模型最小集合：图层、蒙版、变换、文本、滤镜、AI 节点
- [ ] B3. 定义视频编辑文档最小集合：片段、轨道、字幕、旁白、BGM、导出配置
- [ ] B4. 定义跨端共享的工作流节点模型与运行状态
- [ ] B5. 区分云端真源状态、本地缓存状态、可同步衍生物

## C. 桌面宿主与 Rust Bridge

- [ ] C1. 确定桌面端 Rust 接入方式：优先 `flutter_rust_bridge` 或等价桥接
- [ ] C2. 为桌面端定义编辑会话生命周期：打开项目、加载缓存、恢复上下文、释放资源
- [ ] C3. 定义桌面端本地缓存目录、代理目录、导出目录约定
- [ ] C4. 明确桌面端与云端同步频率、冲突策略、失败恢复策略

## D. 图片编辑 MVP

- [ ] D1. 先落静态图片素材工作台，而不是 PSD 兼容器
- [ ] D2. 支持裁切、旋转、缩放、平移、文本、基础滤镜
- [ ] D3. 支持蒙版与局部重绘的最小数据结构
- [ ] D4. 接入 AI 抠图 / 扩图 / 重绘任务，并能回写到资产系统
- [ ] D5. 支持批量导出与导出预设
- [ ] D6. 定义桌面端图片编辑与 Web 端图片审核的分工

## E. 视频粗剪 MVP

- [ ] E1. 在现有短视频装配基础上补齐正式时间线编辑文档
- [ ] E2. 支持镜头重排、启停、候选切换、字幕 / 旁白 / BGM 编排
- [ ] E3. 补齐代理生成、波形、时间轴预览元数据
- [ ] E4. 支持批量导出与任务化进度反馈
- [ ] E5. 先控制为粗剪与批量出片，不把首期做成无限轨 NLE

## F. Web / 手机协作面

- [ ] F1. 给 Web / 手机端提供项目查看、素材上传、评论、审核、任务入口
- [ ] F2. 明确哪些按钮是协作态可用、哪些必须跳桌面端
- [ ] F3. 为重型编辑入口增加“桌面端继续”说明，而不是报错式阻断
- [ ] F4. 提供桌面下载页、版本检测、当前项目接力提示

## G. 桌面接力与转化路径

- [ ] G1. 定义 handoff intent：项目 id、路由、可选脚本 / 分镜上下文
- [ ] G2. 支持 Web / 手机端一键复制或扫码继续到桌面端
- [ ] G3. 桌面端登录后自动恢复到目标项目与界面
- [ ] G4. 记录 handoff 成功率、下载转化率、未完成接力原因

## H. AI 工作流编排

- [ ] H1. 定义转录、静音检测、图片生成、视频生成、字幕、导出等节点协议
- [ ] H2. 区分本地执行节点与云端执行节点
- [ ] H3. 统一重试、取消、阶段进度、错误码和结果回写结构
- [ ] H4. 让桌面端可以直接消费同一工作流定义执行本地任务
- [ ] H5. 让服务端承担编排、同步和可选云任务，而不是默认吞掉所有重型执行

## I. 云端任务与成本边界

- [ ] I1. 明确哪些任务默认本地执行，哪些任务可选上云
- [ ] I2. 为夜间批量出片和团队渲染预留 worker 模式
- [ ] I3. 定义云端任务排队、配额、失败重试与取消规则
- [ ] I4. 在产品上明确呈现“本地执行 / 云端执行”的差异

## J. 验收与观测

- [ ] J1. 建立桌面接力成功率指标
- [ ] J2. 建立代理生成、导出、AI 回写耗时指标
- [ ] J3. 建立本地执行 / 云端执行比例指标
- [ ] J4. 建立重型编辑入口的桌面下载转化漏斗
- [ ] J5. 建立跨端项目恢复失败的诊断手册
