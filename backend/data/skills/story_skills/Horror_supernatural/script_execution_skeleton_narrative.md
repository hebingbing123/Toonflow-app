# 恐怖灵异 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：建立正常世界秩序，植入第一个异常信号，主角被迫卷入超自然事件，恐惧感初步建立。
- **第二幕**（中60%）：恐怖事件升级，真相线索逐步揭露，主角在恐惧与求生本能间挣扎，每集至少一次高强度惊吓节点。
- **第三幕**（后20%）：超自然真相揭开，主角以代价换取终结，留有余韵的开放式或悲剧收尾。

## 分集策略

- 每集设置一个独立恐怖事件，同时推进核心谜题。
- 集末以新的异常现象或人物失踪收尾，制造持续恐惧感。
- 每3集揭露一条关键线索，维持悬疑与恐怖的双重张力。

## 付费卡点设计

- 卡点设在恐怖高潮前一刻，利用极度紧张感驱动付费。
- 真相即将揭露的关键场景前设付费解锁。
- 主角陷入绝境时设卡，确保情绪积累充分。
