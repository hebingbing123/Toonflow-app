# 恐怖灵异 — 剧本台词与场景规范

## 台词风格

- 台词简短紧张，恐惧状态下人物语言碎片化、不连贯。
- 超自然存在的台词要有异质感，避免过于人性化的表达。
- 恐惧台词多用疑问和否定，体现认知崩溃的心理状态。
- 关键线索台词要隐晦，让观众在事后回味时产生后怕感。

## 场景描写

- 场景描写强调光线、声音、气温等感官异常，营造不安氛围。
- 恐怖元素要先用环境暗示，再逐步具象化，避免直接呈现。
- 日常场景的细微异常比直接的恐怖元素更有效（镜中倒影、错位的影子）。
- 场景空间要有压迫感，封闭、狭窄、光线不足的环境强化恐惧。

## 情绪表达

- 恐惧情绪要有层次：不安→疑惑→惊恐→绝望，逐步升级。
- 避免角色持续处于极度恐惧状态，需要情绪缓冲区维持张力。
- 恐惧与好奇的矛盾心理是驱动角色行动的核心情绪动力。
- 高潮恐惧场景后要有短暂的情绪释放，再引入新的恐惧。
