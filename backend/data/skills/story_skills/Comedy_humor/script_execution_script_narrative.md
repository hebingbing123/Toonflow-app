# 喜剧幽默 — 剧本台词与场景规范

## 台词风格

- 台词节奏轻快，多用短句和反问，制造喜剧节拍感。
- 善用误解性语言：同一句话在不同语境下产生双重含义。
- 禁止说教式台词；幽默来自情境而非刻意搞笑的语气词。
- 角色台词要有鲜明个性差异，形成喜剧对比效果。

## 场景描写

- 场景设置强调日常性，荒诞感从普通场景中自然生长。
- 道具和环境细节可作为笑点载体（如错放的物品、意外的背景）。
- 场景切换节奏快，避免长时间停留在单一空间。
- 多人场景注重空间关系，利用位置错位制造视觉喜剧效果。

## 情绪表达

- 角色情绪反应要夸张但有逻辑，避免无缘由的崩溃或狂喜。
- 喜剧情绪曲线：尴尬积累→爆发→意外化解，节奏要紧凑。
- 情绪转折要快，不在悲伤或愤怒情绪上停留过长。
- 结尾情绪以轻松释然为主，给观众愉悦的情感出口。
