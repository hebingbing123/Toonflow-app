# 喜剧幽默 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：建立荒诞前提或误会根源，主角陷入尴尬困境，快速抛出核心笑点钩子。
- **第二幕**（中60%）：误会层层叠加，笑料升级，每集至少一个反转或意外，节奏轻快不拖沓。
- **第三幕**（后20%）：误会揭开，情感和解，以温情或出人意料的方式收尾，留下余笑。

## 分集策略

- 每集聚焦一个独立笑点事件，同时推进主线误会。
- 集末以新的尴尬或反转收尾，驱动观众追下一集。
- 每3集设置一次误会升级节点，防止笑料重复疲劳。

## 付费卡点设计

- 卡点优先放在误会即将揭穿的前一刻，制造"差一步"悬念。
- 主角即将出糗的高潮时刻设为付费解锁点。
- 避免在纯铺垫场景设卡，确保卡点前有足够情绪积累。
