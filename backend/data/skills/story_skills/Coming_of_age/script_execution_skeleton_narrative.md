# 成长青春 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：主角面临成长转折点（升学、初恋、家庭变故），建立内心渴望与现实阻碍的张力。
- **第二幕**（中60%）：经历挫折、友情考验、自我怀疑，每集推进一次成长认知的突破或倒退。
- **第三幕**（后20%）：主角完成内心蜕变，以更成熟的姿态面对原有困境，情感升华收尾。

## 分集策略

- 每集围绕一个成长课题（勇气、诚实、放手等），形成独立情感单元。
- 集末以主角内心独白或关键选择收尾，引发观众共鸣与期待。
- 每4集设置一次人物关系重大转变，推动主线成长弧。

## 付费卡点设计

- 卡点设在主角面临重大抉择的瞬间（表白、离开、和解）。
- 友情或亲情破裂的高潮冲突后设付费解锁。
- 确保卡点前有充分的情感铺垫，让观众产生强烈代入感。
