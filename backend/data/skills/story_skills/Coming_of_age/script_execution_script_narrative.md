# 成长青春 — 剧本台词与场景规范

## 台词风格

- 台词真实自然，贴近青少年日常语言，避免成人化说教。
- 多用不完整句和停顿，表现青春期的迷茫与欲言又止。
- 重要情感台词要简洁有力，避免过度解释内心感受。
- 同伴间对话轻松随意，与家长/老师对话形成语气反差。

## 场景描写

- 场景以校园、家庭、街头为主，细节要有时代感和青春气息。
- 重要成长时刻选择有象征意义的场景（操场、天台、毕业典礼）。
- 季节和光线变化配合情绪节点，如夏末对应离别，春天对应新生。
- 避免过度美化场景，保留真实生活的粗粝感。

## 情绪表达

- 情绪表达要克制而真实，青春期的情感往往是压抑后的爆发。
- 避免直白的情感宣泄，多用行为和细节暗示内心状态。
- 成长顿悟时刻要有具体触发点，不能凭空升华。
- 情绪曲线：压抑→爆发→沉淀→成长，每个阶段都要有场景支撑。
