# 热血动作 — 剧本台词与场景规范

## 台词风格

- 台词简洁有力，热血宣言要短促有冲击力，避免冗长的战前演讲。
- 战斗中台词极简，动作本身是最强的表达。
- 伙伴情义台词要真诚直接，不拐弯抹角，体现热血人物的坦荡。
- 反派台词要有压迫感，强调实力差距，为主角逆转蓄势。

## 场景描写

- 战斗场景描写要有动态感，强调力量、速度、冲击的具象表现。
- 训练和突破场景要有环境配合（极端天气、险峻地形），强化热血感。
- 伙伴并肩场景要有空间上的并列感，体现团队凝聚力。
- 胜利场景不过度渲染，保留克制的热血美学。

## 情绪表达

- 热血情绪要有爆发点，不能全程高亢，需要低谷来衬托高潮。
- 挫败时的情绪要真实沉重，是热血觉醒的必要前提。
- 逆转时刻的情绪爆发要有充分的前期积累，一击必杀的情感冲击。
- 情绪曲线：挫败→隐忍→觉醒→爆发→胜利，节奏紧凑有力。
