# 热血动作 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：主角实力被低估或遭受重大挫败，确立核心仇恨或目标，热血觉醒的种子埋下。
- **第二幕**（中60%）：主角不断突破极限，每集一场升级对决，伙伴情义与强敌压迫交替推进，热血值持续攀升。
- **第三幕**（后20%）：终极对决爆发，主角以意志力突破极限，完成蜕变，热血收尾兼顾情感升华。

## 分集策略

- 每集必有一场战斗或对抗，强度逐集递增。
- 集末以主角险胜或新强敌登场收尾，保持热血节奏。
- 每4集设置一次实力跃升节点，给观众明确的成长感。

## 付费卡点设计

- 卡点设在终极对决开始前，利用期待感驱动付费。
- 主角陷入绝境、即将逆转的瞬间设付费解锁。
- 新强敌登场或秘密武器揭晓前必设卡点。
