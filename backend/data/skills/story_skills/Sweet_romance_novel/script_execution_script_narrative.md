# 甜宠言情 — 剧本台词与场景规范

## 台词风格

- 台词甜蜜自然，男主台词要有霸气中的温柔，女主台词要有可爱中的坚韧。
- 甜蜜互动台词要有专属感，体现两人之间独特的相处方式。
- 误会台词要有合理性，避免一句话就能解释清楚的低级误会。
- 告白台词要简洁有力，情感积累到位后无需过多修饰。

## 场景描写

- 甜蜜场景选择有浪漫感的环境（夕阳、雨中、节日氛围）。
- 日常互动场景要有生活细节，甜蜜感来自真实的相处细节。
- 误会场景要有空间上的距离感，物理距离映射情感距离。
- 告白场景要有仪式感，环境细节配合情感高潮。

## 情绪表达

- 甜蜜情绪要有层次：心动→暧昧→确认，每个阶段都有独特的情感质感。
- 误会带来的痛苦要真实，是甜蜜的必要对比，不能轻描淡写。
- 心动时刻的情绪要细腻，用具体的身体反应（心跳加速、脸红）代替抽象描述。
- 情绪曲线：心动萌芽→甜蜜升温→误会危机→深情和解，节奏轻快甜蜜。
