# 甜宠言情 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：男女主相遇，建立初始误会或身份差距，甜蜜火花与阻碍同步埋下。
- **第二幕**（中60%）：感情在误会与甜蜜互动中升温，每集一个甜点场景，同时推进阻碍感情的核心矛盾。
- **第三幕**（后20%）：误会化解，感情确认，以高甜告白或浪漫场景完成情感闭环。

## 分集策略

- 每集保证一个甜蜜互动高光时刻，同时推进感情阻碍线。
- 集末以意外亲密接触或情感误会收尾，制造甜蜜悬念。
- 每3集设置一次感情危机节点，防止甜度过于平淡。

## 付费卡点设计

- 卡点设在告白或重要甜蜜场景前，利用期待感驱动付费。
- 感情危机最高点（误会最深、分离最近）时设付费解锁。
- 身份秘密即将揭露前必设卡点。
