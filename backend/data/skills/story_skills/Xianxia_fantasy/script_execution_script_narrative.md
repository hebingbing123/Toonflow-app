# 仙侠玄幻 — 剧本台词与场景规范

## 台词风格

- 台词融合古典韵味与现代可读性，重要台词要有诗意感。
- 修炼境界和功法台词要有体系感，专有名词要前后一致。
- 仙侠人物台词要有超脱感，但情感时刻要回归人性温度。
- 大道感悟台词要简洁深刻，避免冗长的修炼心得独白。

## 场景描写

- 场景要有仙侠美学：云海、古刹、灵峰、秘境，自然景观要有灵气感。
- 修炼突破场景要有天地异象的描写，体现境界提升的宏大感。
- 宗门场景要有等级秩序感，建筑和空间布局体现修炼体系。
- 战斗场景要有法术与武技的视觉层次，避免单调的力量对撞。

## 情绪表达

- 仙侠情感要有"情劫"感，情感越深越是修炼的阻碍与动力。
- 道义抉择时的情绪要有天人交战感，个人情感与大道责任的冲突。
- 师徒、道侣情感要克制深沉，仙侠世界的情感往往以行动而非言语表达。
- 情绪曲线：平静修炼→情劫考验→道心动摇→破而后立，节奏悠远深沉。
