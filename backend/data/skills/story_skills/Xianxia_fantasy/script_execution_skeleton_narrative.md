# 仙侠玄幻 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：主角觉醒灵根或获得奇遇，建立修炼体系与宗门/势力格局，核心使命或仇恨埋下。
- **第二幕**（中60%）：修炼突破与宗门争斗交替推进，每集一次境界提升或秘境探索，情感线与修炼线并行。
- **第三幕**（后20%）：终极大战爆发，天道秘密揭露，主角以大道之力完成使命，仙侠意境收尾。

## 分集策略

- 每集推进一次修炼突破或宗门事件，同时深化人物情感。
- 集末以新境界突破或强敌登场收尾，保持修炼爽感。
- 每5集设置一次宗门格局重大变化，推进宏观叙事。

## 付费卡点设计

- 卡点设在重大境界突破或秘境入口前，利用爽感期待驱动付费。
- 天道秘密或身世真相即将揭露时设付费解锁。
- 终极大战开始前必设卡点，确保情绪积累充分。
