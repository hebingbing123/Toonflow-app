# 历史史诗 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：建立历史背景与权力格局，主角卷入时代洪流，确立核心政治或情感冲突。
- **第二幕**（中60%）：权谋博弈与战场厮杀交替推进，主角在忠义、情感、理想间反复抉择，局势多次逆转。
- **第三幕**（后20%）：历史大势落定，主角完成命运使命或悲壮落幕，以宏观视角收束个人与时代的交织。

## 分集策略

- 每集推进一个政治事件或战役节点，同时深化人物关系。
- 集末以局势突变或重要人物命运转折收尾，制造史诗感悬念。
- 每5集设置一次权力格局重大洗牌，保持宏观叙事张力。

## 付费卡点设计

- 卡点设在关键战役或政变前夕，悬念最大化。
- 主角面临生死抉择或背叛揭露时设付费解锁。
- 重大历史转折点前必设卡点，强化史诗感。
