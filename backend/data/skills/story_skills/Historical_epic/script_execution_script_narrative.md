# 历史史诗 — 剧本台词与场景规范

## 台词风格

- 台词兼顾历史感与可读性，避免过于晦涩的文言文，但要有古典韵味。
- 权谋对话要有多层含义，表面客套背后暗藏刀锋。
- 重要历史时刻的台词要有分量感，简洁有力，可传诵。
- 不同阶层角色语言风格差异明显（帝王、谋士、武将、平民各有语气）。

## 场景描写

- 场景要体现历史时代的宏大感（宫殿、战场、市井、边关）。
- 服饰、器物、礼仪细节要符合历史背景，增强真实感。
- 战争场景注重战略层面的描写，而非单纯的厮杀细节。
- 宫廷场景强调空间的权力象征，位置与距离暗示地位关系。

## 情绪表达

- 情绪表达要克制内敛，历史人物的情感往往被责任与大局压制。
- 英雄悲情时刻要有历史宿命感，个人情感与时代洪流的碰撞。
- 避免现代化的情绪表达方式，保持历史人物的时代特征。
- 情绪曲线：隐忍→爆发→悲壮→升华，体现史诗格局。
