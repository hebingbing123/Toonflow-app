# 都市职场 — 剧本台词与场景规范

## 台词风格

- 台词要有职场语境的专业感，融入行业术语但不过度堆砌。
- 职场博弈台词要有表面客气、暗藏锋芒的双层结构。
- 主角台词要体现专业能力，用具体的业务判断展示实力而非自我标榜。
- 职场情感台词要克制，在专业关系中流露真实情感更有张力。

## 场景描写

- 场景以办公室、会议室、商务场合为主，细节体现职场权力关系。
- 职场阴谋场景要有空间上的隐蔽感（走廊低语、会议室外的偷听）。
- 主角展示能力的场景要有具体的工作内容，避免抽象的"表现出色"。
- 职场社交场景（饭局、酒会）是权力博弈的重要舞台，细节要真实。

## 情绪表达

- 职场情绪要克制专业，愤怒和委屈要在私下场合才能释放。
- 职业成就感的情绪要真实，避免过于夸张的胜利庆祝。
- 被背刺时的情绪处理要有层次：震惊→冷静分析→反击策略。
- 情绪曲线：职场压力→隐忍蓄力→关键博弈→突破蜕变，节奏紧凑现实。
