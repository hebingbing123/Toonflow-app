# 都市职场 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：主角进入职场或面临职业危机，建立职场权力格局与核心竞争关系，目标明确。
- **第二幕**（中60%）：职场博弈升级，每集推进一次利益冲突或职场阴谋，个人成长与情感线并行推进。
- **第三幕**（后20%）：主角凭借能力与智慧突破困局，完成职业蜕变，情感线同步收尾。

## 分集策略

- 每集聚焦一个职场事件（项目竞争、背刺、晋升），形成独立职场单元。
- 集末以职场反转或新阴谋浮现收尾，保持追剧动力。
- 每4集设置一次职场格局重大洗牌，推进主线进程。

## 付费卡点设计

- 卡点设在职场关键对决或重要晋升节点前。
- 幕后黑手身份即将揭露时设付费解锁。
- 主角被陷害或面临职业危机最高点时必设卡点。
