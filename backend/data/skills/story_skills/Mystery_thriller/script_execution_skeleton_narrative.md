# 悬疑惊悚 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：核心谜题抛出（案件、失踪、阴谋），建立多个可疑方向，主角被迫介入调查。
- **第二幕**（中60%）：线索与误导交替出现，每集揭露一个局部真相同时引入新疑点，紧张感持续升级。
- **第三幕**（后20%）：真相全面揭露，幕后黑手身份确认，以出人意料的反转完成逻辑闭环。

## 分集策略

- 每集围绕一条线索展开，结尾推翻或强化前集判断。
- 集末以新证据或新危险收尾，制造强烈追剧动力。
- 每3集设置一次重大误导反转，保持悬疑张力。

## 付费卡点设计

- 卡点设在关键证据即将揭露前，利用信息渴望驱动付费。
- 真凶身份即将确认的场景前设付费解锁。
- 主角陷入危险或被反将一军时必设卡点。
