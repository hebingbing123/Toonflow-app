# 悬疑惊悚 — 剧本台词与场景规范

## 台词风格

- 台词要有信息密度，每句对话都可能是线索或误导，避免废话。
- 关键信息台词要自然融入对话，不能像在背诵线索清单。
- 审讯和对峙台词要有节奏感，问答之间的停顿和回避同样重要。
- 反派台词要有智识感，体现与主角的智力博弈。

## 场景描写

- 场景描写强调细节的异常感，普通环境中的不合理之处是悬疑的核心。
- 案发现场描写要精准克制，避免过度渲染血腥，聚焦关键证据细节。
- 追逐和对峙场景要有空间感，利用环境制造紧张的地理博弈。
- 夜晚、雨天、密闭空间是悬疑场景的经典配置，合理运用。

## 情绪表达

- 主角情绪要在理性分析与直觉恐惧之间保持张力。
- 真相揭露时的情绪要有层次：震惊→理解→愤怒→行动。
- 避免角色过于冷静或过于情绪化，保持可信的心理真实感。
- 悬疑情绪曲线：疑惑→紧张→误导→真相冲击，每个节点都要有情绪锚点。
