# 心理剧情 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：呈现主角表面正常的生活，植入心理创伤或认知扭曲的暗示，建立内外世界的张力。
- **第二幕**（中60%）：心理压力逐步激化，现实与内心世界的边界模糊，人物关系在信任与怀疑间反复撕裂。
- **第三幕**（后20%）：心理真相揭露，主角完成自我和解或走向崩溃，以深刻的情感余震收尾。

## 分集策略

- 每集深挖一个心理层面（童年创伤、人格面具、执念根源等）。
- 集末以主角行为的反常或新的心理线索收尾，引发观众深度思考。
- 每4集设置一次心理认知的重大颠覆，推动叙事深度。

## 付费卡点设计

- 卡点设在心理真相即将揭露的关键场景前。
- 主角精神崩溃或重大认知反转时设付费解锁。
- 避免在内心独白段落设卡，保持沉浸感。
