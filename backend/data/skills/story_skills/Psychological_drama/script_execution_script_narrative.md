# 心理剧情 — 剧本台词与场景规范

## 台词风格

- 台词多层次，表面意思与潜台词之间存在明显张力。
- 心理独白要有内在逻辑的自洽性，即使是扭曲的认知也要有其合理性。
- 对话中的沉默和回避与台词本身同等重要，要在场景描写中标注。
- 避免直白的心理分析台词，让观众自行解读角色的心理状态。

## 场景描写

- 场景描写要区分现实与心理空间，两者的视觉风格要有明显差异。
- 心理创伤场景要有具体的感官触发物（气味、声音、特定物品）。
- 现实场景的细节要暗示心理状态，如凌乱的房间对应混乱的内心。
- 镜子、水面、玻璃等反射元素是心理剧的重要场景符号。

## 情绪表达

- 情绪表达要有压抑感，心理剧的情感力量来自克制而非爆发。
- 心理崩溃时刻要有具体的触发事件，不能无缘由地突然崩溃。
- 情绪的矛盾性是心理剧的核心：爱与恨、恐惧与渴望同时存在。
- 情绪曲线：表面平静→内心涌动→压抑爆发→心理重建，节奏深沉。
