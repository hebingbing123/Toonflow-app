# 家庭温情 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：呈现家庭日常裂痕或外部压力，建立家庭成员间的情感隔阂与潜在矛盾。
- **第二幕**（中60%）：矛盾在日常小事中激化，家庭成员各自经历考验，温情细节穿插其中缓和张力。
- **第三幕**（后20%）：家庭成员相互理解，裂痕愈合，以温暖团聚或释怀的方式完成情感闭环。

## 分集策略

- 每集聚焦一个家庭成员的视角或一件家庭小事，积累情感厚度。
- 集末以温情细节或小和解收尾，给观众情感满足感同时留下新悬念。
- 每3集推进一次家庭关系的重要转变节点。

## 付费卡点设计

- 卡点设在家庭矛盾激化的关键冲突场景后。
- 重要家庭秘密即将揭露前设付费解锁。
- 避免在温情日常段落设卡，保持情感流畅性。
