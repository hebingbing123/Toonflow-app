# 家庭温情 — 剧本台词与场景规范

## 台词风格

- 台词贴近家庭日常，多用生活化口语，避免戏剧化的激烈对白。
- 家庭矛盾台词要有"话里有话"的层次，表面争吵背后是爱与担忧。
- 温情时刻台词要简短真诚，避免煽情过度的长篇独白。
- 不同代际角色语言风格要有明显差异，体现代沟与理解。

## 场景描写

- 场景以家庭空间为核心（餐桌、厨房、客厅），细节要有生活温度。
- 重要情感场景选择有家庭记忆的地点（老房子、家庭相册、共同做饭）。
- 食物、气味、声音等感官细节是家庭温情的重要载体。
- 场景布置要体现家庭历史感，避免过于精致的布景。

## 情绪表达

- 情绪表达以细腻克制为主，温情来自细节积累而非直接煽情。
- 家庭和解时刻要有具体行动支撑（一个拥抱、一顿饭、一句迟来的道歉）。
- 避免过于戏剧化的情绪爆发，家庭情感的力量在于日常积累。
- 情绪曲线：日常摩擦→误解加深→理解触发→温情和解，节奏舒缓。
