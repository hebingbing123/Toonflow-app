# 科幻末世 — 剧本骨架叙事规范

## 三幕结构划分

- **第一幕**（前20%）：建立末世世界观与生存规则，主角面临生死威胁，确立求生目标或反抗使命。
- **第二幕**（中60%）：在废土或高科技压迫环境中求生，每集推进一次世界观揭秘或势力冲突，人性考验贯穿始终。
- **第三幕**（后20%）：末世根源真相揭露，主角以牺牲或突破完成使命，开放式结局留有续集空间。

## 分集策略

- 每集聚焦一个生存挑战或世界观碎片，逐步拼出末世全貌。
- 集末以新威胁或世界观颠覆性揭露收尾，保持探索欲。
- 每4集设置一次势力格局重大变化，推进宏观叙事。

## 付费卡点设计

- 卡点设在末世真相即将揭露的关键节点前。
- 主角面临生死抉择或重要伙伴牺牲时设付费解锁。
- 新区域探索或重大科技秘密揭晓前必设卡点。
