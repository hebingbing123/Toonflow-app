# 科幻末世 — 剧本台词与场景规范

## 台词风格

- 台词融入世界观专有词汇，但要确保观众能从语境中理解含义。
- 末世生存者台词要有疲惫感和实用主义色彩，少谈理想多谈生存。
- 科技相关台词要有专业感但不晦涩，避免堆砌无意义的科幻术语。
- 人性讨论台词要自然融入生存困境，避免刻意的哲学说教。

## 场景描写

- 末世场景要有废墟美学：破败中保留文明遗迹，形成强烈视觉对比。
- 科技元素与自然侵蚀并存，体现文明崩溃后的时间感。
- 生存基地场景要有功能性细节，体现末世人类的适应智慧。
- 危险区域描写强调环境威胁的具体性（辐射、变异生物、极端气候）。

## 情绪表达

- 末世情绪基调是压抑中的顽强，绝望与希望的持续拉锯。
- 人性考验时刻的情绪要真实复杂，避免非黑即白的道德判断。
- 伙伴牺牲的情绪处理要克制，末世生存者已习惯失去。
- 情绪曲线：绝望→求生本能→人性考验→微弱希望，节奏沉重而有力。
