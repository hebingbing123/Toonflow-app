# 短视频轻量剪辑工作台 - 快捷键参考

本文档列出了短视频轻量剪辑工作台的所有快捷键，帮助您提高工作效率。

## 快捷键说明

- **Windows/Linux**：使用 `Ctrl` 键
- **Mac**：使用 `Cmd` 键（⌘）
- 本文档中使用 `Ctrl/Cmd` 表示两个平台的对应键

---

## 通用快捷键

### 文件操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + S` | 保存草稿 | 保存当前工作状态到草稿 |
| `Ctrl/Cmd + Shift + S` | 创建版本 | 创建新的项目版本 |

### 编辑操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + Z` | 撤销 | 撤销最近的一次操作 |
| `Ctrl/Cmd + Shift + Z` | 重做 | 重做刚才撤销的操作 |
| `Ctrl/Cmd + Y` | 重做（备选） | 重做刚才撤销的操作（Windows） |

### 选择操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + A` | 全选 | 选中所有镜头 |
| `Ctrl/Cmd + D` | 取消选择 | 取消所有镜头的选择 |
| `Shift + 点击` | 范围选择 | 选择起始和结束之间的所有镜头 |
| `Ctrl/Cmd + 点击` | 多选 | 添加或移除单个镜头的选择 |

### 搜索和过滤

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + F` | 搜索 | 聚焦到搜索框 |
| `Ctrl/Cmd + Shift + F` | 高级过滤 | 打开高级过滤面板 |
| `Esc` | 清除搜索 | 清除搜索框内容 |

### 对话框操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Esc` | 关闭对话框 | 关闭当前打开的对话框 |
| `Enter` | 确认 | 确认对话框中的操作 |
| `Tab` | 切换焦点 | 在对话框中切换输入焦点 |

## 快捷键冲突解决

### 浏览器快捷键冲突

某些快捷键可能与浏览器默认快捷键冲突：

| 快捷键 | 浏览器功能 | 解决方案 |
|--------|-----------|---------|
| `Ctrl/Cmd + F` | 浏览器搜索 | 应用内搜索优先 |
| `Ctrl/Cmd + S` | 保存网页 | 应用内保存优先 |
| `F11` | 浏览器全屏 | 使用 `F` 键进入视频全屏 |

**建议**：使用 Chrome 或 Edge 浏览器，兼容性最好。

### 操作系统快捷键冲突

某些快捷键可能与操作系统快捷键冲突：

| 快捷键 | 系统功能 | 解决方案 |
|--------|---------|---------|
| `Ctrl/Cmd + Space` | 输入法切换 | 使用 `Space` 键播放/暂停 |
| `Ctrl/Cmd + Tab` | 切换窗口 | 使用 `Tab` 键切换焦点 |

**建议**：在应用内使用快捷键时，确保焦点在应用窗口内。

## 自定义快捷键

### 如何自定义快捷键

1. 点击右上角的"设置"按钮
2. 选择"快捷键设置"
3. 点击要修改的快捷键
4. 按下新的快捷键组合
5. 点击"保存"

**注意**：
- 不能使用已被占用的快捷键
- 不能使用单个字母键（避免与输入冲突）
- 建议使用 `Ctrl/Cmd` 或 `Alt/Option` 组合键

### 恢复默认快捷键

1. 点击右上角的"设置"按钮
2. 选择"快捷键设置"
3. 点击"恢复默认"按钮
4. 确认恢复

## 常见问题

**Q: 快捷键不生效？**

A: 请检查：
1. 焦点是否在应用窗口内
2. 是否有对话框打开（某些快捷键在对话框中不可用）
3. 是否与浏览器或系统快捷键冲突
4. 尝试刷新页面

**Q: 如何查看所有快捷键？**

A: 按下 `Ctrl/Cmd + /` 或点击右上角的"帮助"按钮，选择"快捷键列表"。

**Q: 可以自定义快捷键吗？**

A: 可以。在设置中选择"快捷键设置"，点击要修改的快捷键，按下新的快捷键组合即可。

**Q: Mac 和 Windows 的快捷键有什么区别？**

A: 主要区别是修饰键：
- Windows/Linux 使用 `Ctrl` 键
- Mac 使用 `Cmd` 键（⌘）
- 其他键位基本相同
