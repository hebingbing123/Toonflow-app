## 预览播放

### 单镜头预览

在镜头列表中，每个镜头卡片上都有一个**预览按钮**（播放图标）。点击后会打开预览对话框，显示：

- 视频播放器
- 播放控制按钮（播放/暂停/停止）
- 进度条和时间显示
- 镜头信息（序号、时长、字幕等）

### 成片连续播放

在预览对话框中，您可以：

- **连续播放**：自动播放所有启用的镜头
- **上一个/下一个**：使用按钮或键盘方向键切换镜头
- **总进度显示**：查看整体播放进度和当前镜头位置
- **跳转播放**：点击进度条跳转到指定位置

**提示**：预览功能会自动跳过已禁用的镜头。

## 批量操作

### 选择镜头

批量操作工具栏位于镜头列表上方，提供以下选择方式：

1. **单选**：点击镜头卡片左上角的复选框
2. **全选**：点击工具栏的"全选"按钮
3. **范围选择**：按住 Shift 键，点击起始和结束镜头

工具栏会显示当前选中的镜头数量。

### 批量启用/禁用

选中镜头后，点击"启用"或"禁用"按钮：

- **启用**：将选中的镜头标记为启用状态，包含在成片中
- **禁用**：将选中的镜头标记为禁用状态，不包含在成片中

系统会显示进度对话框，展示操作进度和结果统计。

### 批量时长对齐

选中镜头后，点击"时长对齐"按钮：

1. 输入目标时长（1-300 秒）
2. 系统会将所有选中镜头的时长调整为目标值
3. 查看操作结果（成功/失败统计）

**注意**：时长对齐会影响视频播放速度，请谨慎使用。

### 批量配音生成

选中镜头后，点击"批量配音"按钮：

1. 选择 TTS 供应商和声线
2. 调整情绪和语速参数
3. 系统会为所有选中镜头生成配音
4. 查看生成进度和结果

**提示**：批量配音最多支持 5 个并发任务，大量镜头可能需要较长时间。

### 重试失败项

如果批量操作中有失败项，进度对话框会显示失败列表。您可以：

- 查看失败原因
- 点击"重试失败项"按钮重新执行
- 单独处理失败的镜头

## 过滤和搜索

### 搜索功能

在过滤面板的搜索框中输入关键词，系统会在以下内容中搜索：

- 镜头字幕
- 镜头旁白
- 镜头描述

搜索支持：
- **实时搜索**：输入后自动搜索（300ms 防抖）
- **全文匹配**：支持中文、英文、数字
- **高亮显示**：搜索结果会在列表中高亮显示

### 状态过滤

使用状态下拉菜单过滤镜头：

- **全部**：显示所有镜头
- **已启用**：只显示启用的镜头
- **已禁用**：只显示禁用的镜头
- **有配音**：只显示已生成配音的镜头
- **无配音**：只显示未生成配音的镜头

### 质量过滤

使用质量下拉菜单过滤镜头：

- **全部**：显示所有质量等级
- **优秀**：只显示质量评分 >= 90 的镜头
- **良好**：只显示质量评分 70-89 的镜头
- **一般**：只显示质量评分 < 70 的镜头

### 组合过滤

您可以同时使用多个过滤条件，系统会应用 AND 逻辑：

- 搜索 + 状态过滤
- 搜索 + 质量过滤
- 状态 + 质量过滤
- 搜索 + 状态 + 质量

当前应用的过滤条件会以标签形式显示在过滤面板下方。

### 过滤预设

保存常用的过滤组合：

1. 设置好过滤条件
2. 点击"保存预设"按钮
3. 输入预设名称
4. 下次使用时，从预设列表中选择即可

**提示**：点击"清除所有过滤"可以快速重置所有过滤条件。

## 版本管理

### 创建版本

版本管理允许您保存项目的不同状态：

1. 点击"版本管理"按钮
2. 点击"创建新版本"
3. 输入版本名称和描述
4. 系统会保存当前的所有镜头状态

**用途**：
- 保存重要的里程碑
- 尝试不同的剪辑方案
- 回退到之前的状态

### 切换版本

在版本列表中：

1. 选择要切换的版本
2. 点击"切换"按钮
3. 系统会加载该版本的所有镜头状态

**注意**：切换版本前，系统会提示您保存当前更改。

### 草稿管理

草稿是临时保存的工作状态：

- **自动保存**：系统每 5 分钟自动保存草稿
- **手动保存**：点击"保存草稿"按钮（快捷键：Ctrl+S / Cmd+S）
- **草稿列表**：查看最近的 10 个草稿
- **恢复草稿**：选择草稿并点击"恢复"

**提示**：草稿不会永久保存，建议重要更改创建正式版本。

### 版本对比

对比两个版本的差异：

1. 在版本列表中选择两个版本
2. 点击"对比"按钮
3. 查看差异报告：
   - 新增的镜头（绿色）
   - 删除的镜头（红色）
   - 修改的镜头（黄色）
   - 差异统计

您可以导出对比报告为 PDF 或 Excel 文件。

## 撤销和重做

### 撤销操作

如果您不小心执行了错误操作，可以使用撤销功能：

- **快捷键**：Ctrl+Z（Windows/Linux）或 Cmd+Z（Mac）
- **按钮**：点击工具栏的"撤销"按钮

系统会撤销最近的一次操作，并恢复到之前的状态。

### 重做操作

如果您撤销了不该撤销的操作，可以使用重做功能：

- **快捷键**：Ctrl+Shift+Z（Windows/Linux）或 Cmd+Shift+Z（Mac）
- **按钮**：点击工具栏的"重做"按钮

系统会重新执行刚才撤销的操作。

### 操作历史

查看操作历史：

1. 点击"操作历史"按钮
2. 查看最近 50 条操作记录
3. 每条记录显示：
   - 操作类型（编辑、删除、批量操作等）
   - 操作时间
   - 操作描述

**支持的操作类型**：
- 编辑镜头（字幕、旁白、时长等）
- 启用/禁用镜头
- 批量操作
- 版本切换
- 草稿恢复

**注意**：操作历史仅在当前会话中保存，关闭页面后会清空。

## TTS 配音

### 单镜头配音

为单个镜头生成配音：

1. 点击镜头卡片上的"配音"按钮
2. 在配音设置对话框中：
   - 选择 TTS 供应商（OpenAI、Azure 等）
   - 选择声线 ID（alloy、echo、fable 等）
   - 调整情绪（neutral、happy、sad 等）
   - 调整语速（0.5x - 2.0x）
3. 点击"生成"按钮
4. 等待生成完成（通常 2-5 秒）

### 配音预览

生成配音后，您可以：

- **播放配音**：点击播放按钮试听
- **调整音量**：使用音量滑块
- **查看波形**：查看音频波形或进度条
- **重新生成**：如果不满意，可以调整参数重新生成

### 批量配音

为多个镜头批量生成配音：

1. 选中需要配音的镜头
2. 点击"批量配音"按钮
3. 设置统一的配音参数
4. 系统会依次为所有镜头生成配音
5. 查看进度和结果统计

**提示**：
- 批量配音最多支持 5 个并发任务
- 失败的镜头可以单独重试
- 配音文件会自动保存到项目中

### TTS 供应商和声线

**OpenAI TTS**：
- alloy：中性、平衡的声音
- echo：温暖、友好的声音
- fable：富有表现力的声音
- onyx：深沉、权威的声音
- nova：明亮、活泼的声音
- shimmer：柔和、舒缓的声音

**Azure TTS**：
- 支持多种语言和地区
- 提供更多声线选择
- 支持 SSML 标记

**注意**：不同供应商的定价和质量可能不同，请根据需求选择。

## 视频导出

### 导出设置

导出成片视频：

1. 点击"导出"按钮
2. 在导出设置对话框中：
   - **格式**：选择 MP4、MOV 或 WebM
   - **分辨率**：选择 720p、1080p 或 4K
   - **码率**：选择低、中、高或自定义
   - **帧率**：选择 24fps、30fps 或 60fps
3. 查看预估文件大小
4. 点击"开始导出"

### 导出进度

导出过程中，系统会显示：

- **当前阶段**：准备中、编码中、上传中
- **进度百分比**：0-100%
- **预计剩余时间**：根据当前速度估算
- **取消按钮**：可以随时取消导出

**导出阶段**：
1. **准备中**：收集镜头素材和配音
2. **编码中**：合成视频和音频
3. **上传中**：上传到云存储
4. **完成**：生成下载链接

### 导出历史

查看历史导出记录：

1. 点击"导出历史"按钮
2. 查看所有导出任务：
   - 任务状态（进行中、已完成、失败）
   - 导出时间
   - 文件大小
   - 下载链接
3. 可以按状态和时间过滤
4. 可以重新下载已完成的导出

**提示**：
- 导出文件会保留 30 天
- 最多同时进行 3 个导出任务
- 失败的任务可以重新导出

### 导出格式说明

**MP4**：
- 最通用的格式
- 兼容性最好
- 文件大小适中
- 推荐用于分享和上传

**MOV**：
- Apple 生态系统优化
- 支持更高质量
- 文件大小较大
- 推荐用于 iOS/Mac 设备

**WebM**：
- 开源格式
- 文件大小最小
- 网页播放优化
- 推荐用于网页嵌入

### 质量参数说明

**分辨率**：
- 720p (1280x720)：适合移动设备
- 1080p (1920x1080)：标准高清，推荐
- 4K (3840x2160)：超高清，文件大

**码率**：
- 低（2 Mbps）：文件小，质量一般
- 中（5 Mbps）：平衡，推荐
- 高（10 Mbps）：质量好，文件大
- 自定义：手动设置码率值

**帧率**：
- 24fps：电影感，文件小
- 30fps：标准，推荐
- 60fps：流畅，文件大

## 常见问题

### 预览播放

**Q: 预览视频无法播放？**

A: 请检查：
1. 视频文件是否已上传完成
2. 浏览器是否支持视频格式
3. 网络连接是否正常
4. 尝试刷新页面

**Q: 预览播放卡顿？**

A: 可能原因：
1. 网络速度较慢，视频加载不及时
2. 视频分辨率过高
3. 浏览器性能不足
4. 建议使用 Chrome 或 Edge 浏览器

### 批量操作

**Q: 批量操作失败？**

A: 请检查：
1. 是否选中了镜头
2. 网络连接是否正常
3. 查看失败列表中的错误信息
4. 尝试重试失败项

**Q: 批量操作进度很慢？**

A: 这是正常的：
1. 系统限制了并发数量（最多 10 个）
2. 大量镜头需要较长时间
3. 可以先处理部分镜头
4. 可以在后台运行，继续其他工作

### 过滤和搜索

**Q: 搜索没有结果？**

A: 请检查：
1. 关键词是否正确
2. 是否有其他过滤条件限制
3. 尝试清除所有过滤条件
4. 检查镜头是否真的包含该关键词

**Q: 过滤条件不生效？**

A: 可能原因：
1. 过滤条件冲突（如同时选择"已启用"和"已禁用"）
2. 浏览器缓存问题，尝试刷新页面
3. 检查是否有其他过滤条件

### 版本管理

**Q: 无法创建版本？**

A: 请检查：
1. 版本名称是否为空
2. 是否已达到版本数量上限（100 个）
3. 网络连接是否正常
4. 尝试刷新页面

**Q: 切换版本后数据丢失？**

A: 不用担心：
1. 切换版本前系统会提示保存
2. 可以切换回原来的版本
3. 可以查看版本对比确认差异
4. 建议重要更改创建新版本

### TTS 配音

**Q: 配音生成失败？**

A: 可能原因：
1. TTS 服务暂时不可用
2. 配音文本为空或过长
3. 网络连接问题
4. 尝试重新生成或更换供应商

**Q: 配音质量不满意？**

A: 可以尝试：
1. 更换声线 ID
2. 调整情绪和语速参数
3. 优化配音文本（添加标点、调整语气）
4. 尝试不同的 TTS 供应商

### 视频导出

**Q: 导出失败？**

A: 请检查：
1. 是否有启用的镜头
2. 所有镜头的素材是否完整
3. 网络连接是否稳定
4. 查看错误信息并重试

**Q: 导出文件太大？**

A: 可以尝试：
1. 降低分辨率（如从 1080p 改为 720p）
2. 降低码率（如从高改为中）
3. 降低帧率（如从 60fps 改为 30fps）
4. 选择 WebM 格式（文件更小）

**Q: 导出时间太长？**

A: 这是正常的：
1. 视频编码需要时间
2. 时长越长，导出越慢
3. 质量越高，导出越慢
4. 可以在后台运行，继续其他工作

### 性能问题

**Q: 页面加载很慢？**

A: 可能原因：
1. 镜头数量过多（> 1000）
2. 浏览器性能不足
3. 网络速度较慢
4. 系统会自动启用虚拟滚动优化

**Q: 操作响应慢？**

A: 可以尝试：
1. 关闭其他浏览器标签页
2. 清除浏览器缓存
3. 使用性能更好的浏览器（Chrome、Edge）
4. 升级电脑硬件
