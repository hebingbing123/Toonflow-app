# 质量评审量表（Quality Review Rubric）

本量表用于规范人工抽检评审流程，明确各维度定义、评分范围与放行/打回规则，确保评审员按统一标准打分，减少主观漂移。

---

## 评审维度定义

### 1. 画面/人设一致性（`visual_consistency`）

**定义**：画面风格、色调、构图与整体视觉呈现是否与项目设定保持一致；人物外观（服装、发型、肤色、体型）在不同镜头间是否保持稳定。

**评分说明**：

| 分值 | 描述 |
|------|------|
| 9–10 | 画面风格高度统一，人物外观在所有镜头中完全一致，无任何视觉跳变 |
| 7–8  | 整体一致，偶有细微差异（如光影变化），不影响观感 |
| 5–6  | 存在明显但可接受的不一致，需小幅修正 |
| 3–4  | 多处明显不一致，影响观感，需较大修改 |
| 1–2  | 画面风格混乱或人物外观严重漂移，需重做 |

---

### 2. 叙事连贯性（`narrative_coherence`）

**定义**：故事情节的逻辑推进是否流畅，场景转换是否自然，前后情节是否存在矛盾或断层，观众能否顺畅理解叙事脉络。

**评分说明**：

| 分值 | 描述 |
|------|------|
| 9–10 | 叙事逻辑严密，场景衔接自然，无任何情节断层或矛盾 |
| 7–8  | 整体流畅，偶有轻微跳跃，不影响理解 |
| 5–6  | 存在明显叙事断层或逻辑跳跃，需补充过渡 |
| 3–4  | 多处情节矛盾或叙事混乱，需较大修改 |
| 1–2  | 叙事严重不连贯，观众无法理解故事走向，需重做 |

---

### 3. 对口型（`lip_sync`）

**定义**：角色口型动作与对白音频的同步程度；口型开合的时机、幅度是否与语音节奏匹配。

**评分说明**：

| 分值 | 描述 |
|------|------|
| 9–10 | 口型与音频完全同步，无任何延迟或错位 |
| 7–8  | 整体同步，偶有轻微偏差（≤2帧），不影响观感 |
| 5–6  | 存在明显偏差（3–10帧），部分场景口型明显不匹配 |
| 3–4  | 多处严重错位，严重影响观感 |
| 1–2  | 口型与音频完全不同步，需重新制作 |

---

### 4. 节奏（`pacing`）

**定义**：整体剪辑节奏是否与故事情绪、场景氛围相符；镜头时长分配是否合理，既不拖沓也不过于仓促；高潮与舒缓段落的节奏对比是否恰当。

**评分说明**：

| 分值 | 描述 |
|------|------|
| 9–10 | 节奏把控精准，张弛有度，完全符合故事情绪需求 |
| 7–8  | 整体节奏合理，偶有轻微拖沓或仓促，不影响整体观感 |
| 5–6  | 节奏存在明显问题，部分段落过长或过短，需调整 |
| 3–4  | 节奏失控，多处严重拖沓或跳跃，影响观看体验 |
| 1–2  | 节奏完全不符合故事需求，需重新剪辑 |

---

### 5. 人设一致性（`character_consistency`）

**定义**：角色的性格特征、行为模式、说话风格是否在整个作品中保持稳定；角色的动机与决策是否符合其既定人设，不出现无理由的性格突变。

**评分说明**：

| 分值 | 描述 |
|------|------|
| 9–10 | 角色性格鲜明且高度一致，行为完全符合人设逻辑 |
| 7–8  | 整体一致，偶有轻微偏差，在合理范围内 |
| 5–6  | 存在明显人设偏差，部分行为与既定性格不符 |
| 3–4  | 多处人设崩塌，角色行为前后矛盾 |
| 1–2  | 角色性格严重不一致，完全偏离原始人设，需重做 |

---

### 6. 对白自然度（`dialogue_naturalness`）

**定义**：对白语言是否自然流畅，符合角色身份与场景语境；是否避免生硬的书面语或翻译腔；对话节奏是否符合真实交流习惯。

**评分说明**：

| 分值 | 描述 |
|------|------|
| 9–10 | 对白极为自然，完全符合角色身份，无任何生硬感 |
| 7–8  | 整体自然，偶有轻微书面化表达，不影响整体感受 |
| 5–6  | 存在明显生硬或翻译腔，部分对白需修改 |
| 3–4  | 多处对白不自然，严重影响角色塑造 |
| 1–2  | 对白极度生硬或与角色完全不符，需重写 |

---

### 7. 与原著/设定符合度（`faithfulness`）

**定义**：内容是否忠实于原著故事、世界观设定与角色关系；改编部分是否在合理范围内，不违背原著核心精神；关键情节、台词与原著的还原程度。

**评分说明**：

| 分值 | 描述 |
|------|------|
| 9–10 | 高度忠实原著，改编合理且增强了原著精神 |
| 7–8  | 整体符合原著，改编在合理范围内，不违背核心设定 |
| 5–6  | 存在明显偏离，部分关键情节或设定与原著不符 |
| 3–4  | 多处严重偏离原著，影响作品完整性 |
| 1–2  | 严重违背原著精神或核心设定，需重做 |

---

## 放行/打回规则（Pass_Threshold）

评审结果判定基于以下两个条件，**必须同时满足**方可放行：

1. **总分阈值**：`overall_score >= 6`（总体评分不低于 6 分）
2. **维度底线**：`dimension_scores` 中**无任何维度**的分值 ≤ 3（即无 D 级维度）

**判定逻辑**：

```
放行（Pass）= overall_score >= 6 AND 所有维度分值 > 3
打回（Reject）= overall_score < 6 OR 存在任意维度分值 ≤ 3
```

**说明**：

- 即使总分达到 6 分，若任一维度评分 ≤ 3（D 级），仍视为打回，需针对该维度重点修改后重新提交。
- 维度评分为可选项，未填写的维度不参与放行判定；但建议评审员尽量填写所有维度，以便追踪质量趋势。
- 打回的评审记录应在 `next_action` 字段中注明具体修改方向。

## 抽样批次规则

为保证质量监控的持续性与代表性，抽检遵循以下规则：

**基本规则**：每个 Stage 每周至少抽检 **5 条**评审记录。

**Stage 枚举**：

| Stage | 说明 |
|-------|------|
| `story_skeleton` | 故事骨架阶段 |
| `adaptation_strategy` | 改编策略阶段 |
| `director_planning` | 导演规划阶段 |
| `storyboard_table` | 分镜表阶段 |
| `storyboard_panel` | 分镜面板阶段 |
| `video_prompt` | 视频提示词阶段 |

**抽样建议**：

- 优先抽取近期生成的记录，确保反映当前模型版本的质量状态。
- 对于评分较低（`overall_score < 6`）或存在 D 级维度的记录，应纳入 Bad Case 集合（`is_bad_case = true`）。
- 每周抽检结果应在质量工作台中记录，并定期汇总为质量趋势报告。
- 当某 Stage 的周通过率低于 70% 时，建议将该周抽检量提升至 10 条以上。

本量表版本为 `2026-06-01`，Flutter 评审表单将在表单顶部展示此版本号，以便评审员知晓所用量表版本。

如需更新量表（新增/修改维度定义、调整阈值等），请：

1. 修改本文件并更新顶部 `version` 字段（格式：`YYYY-MM-DD`）
2. 同步更新 `backend/src/prompting/quality/dimension.rs` 中的 `VALID_DIMENSION_KEYS`
3. 提交 PR 并通知相关评审员知悉变更内容
