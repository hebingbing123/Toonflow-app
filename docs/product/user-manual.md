# OpenFlow 用户操作手册

本手册面向**使用 OpenFlow 客户端进行短剧创作**的用户（编剧、导演、制片、运营、审片），说明从登录、建项到成片交付的完整操作路径。

| 项目 | 说明 |
|------|------|
| **产品形态** | 商业产品：云端 SaaS 或企业私有化部署 |
| **客户端** | 桌面端（macOS / Windows / Linux）与 Web；由管理员或商务发放安装包 |
| **核心路径** | 项目 → **工作室六步**（剧本 → 美术 → 资产 → 分镜 → 视频 → 成片） |
| **相关文档** | [短视频剪辑用户指南](../features/short-video/user-guide.md)（交付步内「多平台分发」深度说明） |

## 1. 使用前准备

### 1.1 您需要具备的条件

| 条件 | 说明 |
|------|------|
| **账号** | 由管理员在 Supabase Auth / 企业 IdP 中开通；使用邮箱或企业 SSO 登录 |
| **客户端** | 安装官方提供的桌面版或打开已部署的 Web 地址 |
| **API 地址** | 首次登录前确认 **API Base URL**（私有化一般为内网域名；云端由运营提供） |
| **模型配置** | 进行 AI 生成前，需有权限用户在 **设置 → 模型厂商** 中配置 LLM / 图像 / 视频供应商与 API Key（云端可能由平台统一路由） |

### 1.2 推荐屏幕与角色

- **推荐分辨率**：桌面宽度 ≥ 1280px；分镜全屏与审片建议 ≥ 1440px。
- **典型角色**：
  - **编剧 / 策划**：剧本步、小说导入、Agent 改写
  - **美术 / 导演**：美术步、资产步、分镜步
  - **制片 / 技术**：任务中心、视频步、交付步、平台配置
  - **质检 / 运营**：质量评审、交付步「质检」Tab、多平台分发

## 2. 登录与主界面

### 2.1 登录

1. 启动 OpenFlow 客户端或打开 Web 应用。
2. 若首次使用，在设置或登录页填写 **API Base URL**（须与贵司部署的后端一致）。
3. 使用分配的账号密码或企业 SSO 登录。
4. 登录成功后进入 **「你的项目」** 首页。

### 2.2 主界面结构

登录后顶部为 **产品壳（Product Shell）**，主要包括：

| 区域 | 作用 |
|------|------|
| **品牌 / 返回** | 点击 Logo 或「回到项目首页」可回到项目列表 |
| **短剧生产平台链** | 横向流水线：**项目 → 剧本 → 制作 → 任务 → 质量 → 多平台分发**（部分入口需先选中项目） |
| **全局搜索** | 跨项目、剧本、资产、小说等搜索（需登录） |
| **通知** | 任务完成、失败、系统消息 |
| **账户与设置** | 个人资料、模型厂商、工作区、套餐用量等 |

> **注意**：「剧本」「制作」等流水线入口必须在 **已选择项目** 后使用；未选项目时会提示「请先在项目列表中选择一个项目」。

### 2.3 命令面板（推荐）

- 按 **`⌘K`（macOS）或 `Ctrl+K`（Windows/Linux）** 打开命令面板。
- 可快速跳转：项目、工作室步骤、设置等。
- 新用户可在项目内查看 **快速入门** 引导（三步：建项 → 六步工作流 → 命令面板）。

## 3. 项目与进入工作室

### 3.1 新建项目

1. 在 **「你的项目」** 页点击 **「新建项目」**（或「创建项目」）。
2. 按向导完成：
   - **基础信息**：项目名称等
   - **故事前提**：可选粘贴小说大纲或正文，作为项目故事前提保存
   - **确认创建**
3. 创建成功后，项目出现在项目网格中。

### 3.2 选择项目并进入工作室

1. **点击项目卡片** 可选中项目范围（用于流水线、任务筛选等上下文）。
2. 点击 **「进入工作室」** 进入该项目的 **六步工作流**（不要只点卡片而不点「进入工作室」）。
3. 工作室顶部显示 **六步条**：**剧本 → 美术 → 资产 → 分镜 → 视频 → 成片**。
4. 点击 **「返回项目」** 可回到项目列表。

### 3.3 空项目时建议顺序

若尚无内容，按界面空状态提示操作：

1. 创建项目  
2. 进入工作室，从 **「剧本」** 步导入小说或新建剧本  
3. 在 **设置 → 模型厂商** 配置模型后再触发 AI 生成

## 4. 工作室六步工作流

工作室是单部短剧的 **标准作业程序（SOP）**。建议按顺序推进，也可通过六步条或 `⌘K` 跳转到任意步骤。

各步均可能有 **「步骤准备区」**（默认折叠）：内含模型路由、快捷操作与阶段进度，需要时从紧凑栏打开。

---

### 4.1 第一步：剧本

**目的**：编写或导入剧本，并用 AI 提取角色、场景等结构化信息。

#### 4.1.1 界面分区

| 分区 | 说明 |
|------|------|
| **内容入口（左侧）** | 内联导入小说：链接抓取、选择 `.txt`/`.md` 文件、粘贴片段或单章录入 |
| **Agent 工作区（右侧）** | 与 AI 对话生成剧本、改写、回写到项目 |
| **Tab：内容 / 生成 / 小说 / 剧本 / 提取** | 切换小说章节、剧本列表与提取任务 |

#### 4.1.2 导入小说（常见起点）

**方式 A：链接抓取**

1. 在「链接抓取」输入小说目录页或章节 URL。  
2. 若站点需登录：展开 **「站点认证」**  
   - **桌面端**：可使用 **「应用内登录并获取 Cookie」**（浏览器版需手动粘贴 Cookie 或使用桌面客户端）。  
   - 支持 Cookie、账号密码或组合方式；保存到项目后再抓取。  
3. 点击 **「抓取并导入章节」**，等待章节写入项目。

**方式 B：本地文件**

1. 点击 **「选择小说文件并导入」**，选择 `.txt` 或 `.md`。  
2. 系统自动切章并导入。

**方式 C：粘贴 / 单章**

- 粘贴整本正文试跑，或使用「单章录入」填写标题与正文。

**批量与高级管理**：点击 **「高级工作台」** 打开小说与章节的完整管理界面。

#### 4.1.3 编写与生成剧本

1. 在 **「剧本」** Tab 查看剧本列表；无剧本时按空状态先完成导入或新建。  
2. 打开右侧 **「剧本 Agent」**，输入需求（例如：「根据第 3–5 章改写成 3 场短剧剧本」）。  
3. Agent 生成结果可 **回写** 到项目剧本；在剧本编辑器中核对对白与场景。  
4. 使用 **「提取」** Tab：轮询提取状态，批量提取 **角色 / 场景** 素材，供后续「资产」步使用。

#### 4.1.4 本步完成标准

- 至少有一份可用的剧本版本。  
- 关键角色、场景已提取或可在资产步手动补全。  

---

### 4.2 第二步：美术

**目的**：确定全片 **画风包** 与 **故事风格包**，统一后续图像、分镜与视频的视觉方向。

#### 4.2.1 操作步骤

1. 进入 **「美术」** 步。  
2. （可选）打开 **「立项与品牌约束」**，填写受众、品牌视觉规则等前提，**保存立项信息**。  
3. 在主区域选择 **内置画风包** 与 **故事风格包**。  
4. 点击 **「保存美术设定」**；成功后会提示已保存。  
5. 可选填写 **遗留画风（自由文本）**；优先以风格包为准。

#### 4.2.2 注意

- 修改风格包后 **必须保存**，才会作用于资产、分镜、视频提示词。  
- 本步不涉及具体镜头图，只定「怎么画」。

---

### 4.3 第三步：资产

**目的**：管理 **角色、道具、场景参考图** 等，保证分镜与视频生成时人物、场景一致。

#### 4.3.1 典型操作

| 操作 | 说明 |
|------|------|
| **查看资产库** | 浏览项目下角色、道具等条目 |
| **生成参考图** | 对单资产发起「单图资产生成」或「批量资产生成」任务 |
| **润色提示词** | 使用「资产提示词润色」优化生成描述 |
| **候选与确认** | 在候选网格中 ←→ 切换，**Enter** 确认选用（与全局「抽卡」交互一致） |

#### 4.3.2 与任务的关系

资产生成多为 **异步任务**，提交后：

1. 底部或侧边出现 **任务托盘（Job Tray）** 显示进度。  
2. 完成后会有提示，刷新即可看到新候选图。  
3. 失败时打开 **任务中心** 查看原因并重试。

---

### 4.4 第四步：分镜

**目的**：将剧本拆解为 **镜头列表**，为每个镜头生成画面候选、润色提示词，并整理时间线。

#### 4.4.1 两种界面

| 入口 | 适用场景 |
|------|----------|
| **分镜步（项目内）** | 常规编辑、与六步条联动 |
| **全屏分镜** | 需要大屏审阅、密集改镜时使用 |

#### 4.4.2 典型流程

1. 选择要制作的 **剧本 / 集**。  
2. 使用 Agent 或菜单触发 **「拆解分镜」**，生成镜头列表与描述。  
3. 对每个镜头 **生成画面**（批量或单镜），在候选网格中挑选满意构图。  
4. 必要时 **润色镜头提示词**，保证风格与美术设定一致。  
5. 调整镜头顺序、启用/禁用镜头（影响后续成片装配）。

#### 4.4.3 协作提示

- 分镜阶段改动较频繁；若多人协作，注意 **版本冲突** 时界面顶部的 **冲突提示条**，按提示合并或刷新。  
- 分镜就绪后，工作流引导会提示进入 **视频** 或 **成片** 阶段。

---

### 4.5 第五步：视频

**目的**：基于分镜静帧生成 **动态视频镜头**。

#### 4.5.1 操作步骤

1. 进入 **「视频」** 步。  
2. 选择镜头范围，提交 **「视频生成」** 任务。  
3. 在任务托盘 / 任务中心查看进度。  
4. 生成完成后在步内 **预览** 单镜或连续播放。  
5. 不满意的镜头可回到分镜步换图或重新生成。

#### 4.5.2 注意

- 视频生成耗时较长，并发受套餐限制；第二路任务可能排队。  
- 确保分镜画面与资产设定已锁定，避免反复返工。

---

### 4.6 第六步：成片（交付）

**目的**：**装配成片**、**质量检查**、**导出** 与 **多平台发布**。

交付步包含三个 Tab（部分环境 URL 可使用 `/quality` 别名打开质检）：

| Tab | 作用 |
|-----|------|
| **成片** | 装配输入（分镜 + 资产）、预览合成、导出成片 |
| **发布** | 在已连接平台排期与发布 |
| **质检** | 发布前运行质量门检查 |

#### 4.6.1 成片 Tab

1. 确认分镜与资产 **装配快照** 就绪。  
2. 使用 **「刷新导出预检」** 查看是否满足导出条件。  
3. 配置导出参数后发起 **「视频导出」** 任务。  
4. 在 **评审预览集** 中浏览镜头就绪状态；满足条件时提示 **「可以导出成片」**。  
5. 导出完成后下载或进入发布流程。

#### 4.6.2 质检 Tab

1. 打开 **质检**，按质量门规则检查（一致性、技术规格等）。  
2. 问题镜头会关联到任务或分镜，便于回到前序步骤修改。  
3. 也可在顶栏流水线进入独立 **「质量评审」** 面板做更细的维度打分（见第 6 节）。

#### 4.6.3 发布 Tab

1. 确认平台已在 **平台配置** 中连接。  
2. 在 **发布** Tab **打开发布** 面板，安排渠道与排期。  
3. 详细的多平台剪辑、TTS、批量镜头操作见 [短视频用户指南](../features/short-video/user-guide.md)。

## 5. 任务中心与生成进度

### 5.1 任务托盘（Job Tray）

- 提交生成类操作后，界面底部/侧边出现托盘。  
- 显示进行中、成功、失败任务；点击可查看详情。  
- 一般在 **2 秒内** 出现进度（WebSocket 推送；异常时约 30 秒内轮询兜底）。

### 5.2 任务中心

从流水线 **「任务」** 或分镜/交付步内 **「打开任务中心」** 进入。

| 能力 | 说明 |
|------|------|
| **按项目筛选** | 只看当前项目的生成与导出任务 |
| **状态查看** | 排队中、运行中、成功、失败 |
| **失败处理** | 查看失败原因（如 LLM 未配置、URL 为空等），重试或回前序步骤修改 |
| **阶段分类** | 含剧本提取、资产生成、视频生成、导出成片等类型 |

### 5.3 常见任务类型（用户可见名称）

| 显示名称 | 通常触发位置 |
|----------|----------------|
| 改写剧本 | 剧本 Agent |
| 拆解分镜 | 分镜步 |
| 单图 / 批量资产生成 | 资产步 |
| 资产提示词润色 | 资产步 |
| 视频生成 | 视频步 |
| 视频导出 | 交付步 |
| 短视频预装配 | 交付 / 短视频空间 |

## 6. 质量评审

除交付步内 **质检 Tab** 外，产品壳提供 **「质量评审」** 面板（流水线「质量」）。

### 6.1 适用场景

- 制片 / 质检员对维度打分（画面、剧本、一致性等）。  
- 查看 **质量新鲜度** 与陈旧数据提示。  
- 与任务中心联动：低分或失败任务可跳转排障。

### 6.2 基本操作

1. 在流水线点击 **「质量」**（需平台开启该面板）。  
2. 选择项目与时间范围，查看评审列表或仪表盘。  
3. 对条目打分、备注；需要时打开关联分镜或镜头。  
4. 数据加载失败时使用 **重试**；空状态表示尚无评审记录。

## 8. 团队工作区与账户设置

### 8.1 工作区（Workspace）

- **Personal**：个人创作空间。  
- **Enterprise**：企业团队空间，含成员、角色与数据隔离。  
- 在 **设置 → 工作区** 中切换当前工作区；任务与计费按工作区归属。

### 8.2 设置（账户与设置）

| 设置项 | 说明 |
|--------|------|
| **账户** | 个人资料、语言（支持 7 种界面语言） |
| **套餐与用量** | 查看 Free / 付费档配额与用量；**升级套餐** 可自助购买创作者 / Pro / 工作室档（支付宝等，见 [billing-checkout.md](./billing-checkout.md)） |
| **模型厂商** | 配置 LLM、图像、视频 API（权限由管理员控制） |
| **API 密钥** | 管理个人或项目级密钥（若启用） |
| **工作区** | 成员、邀请、角色 |

### 8.3 平台配置与状态（制片 / 管理员）

| 面板 | 说明 |
|------|------|
| **平台配置** | 连接分发渠道、短剧平台参数 |
| **平台状态** | 查看 Health / 就绪状态 / 指标（若启用） |
| **内容合规** | 合规队列与审核（若启用） |

## 9. 搜索、通知与快捷操作

### 9.1 全局搜索

1. 点击顶栏搜索框，输入 **2–200 个字符** 的关键词。  
2. 结果按 **项目、剧本、资产、小说** 等分组展示。  
3. 点击结果跳转到对应项目或资源（需有访问权限）。

### 9.2 通知中心

- 任务完成、失败、邀请、系统公告等。  
- 部分通知带 **深链**，点击直达相关项目、任务或面板。  
- 可按类型筛选；无通知时显示空状态。

### 9.3 快捷键摘要

| 快捷键 | 功能 |
|--------|------|
| `⌘K` / `Ctrl+K` | 命令面板（跳转项目/步骤/设置） |
| `?` | 分镜全屏等场景下的快捷键帮助 |
| 方向键 | 预览对话框切换镜头（短视频空间） |

## 10. 常见问题

### 10.1 登录与连接

**Q：登录后一片空白或接口报错？**  
- 检查 **API Base URL** 是否正确、网络能否访问后端。  
- 私有化部署确认 VPN / 内网 DNS。  
- 浏览器访问 `https://<你的API>/api/v1/health` 或 Swagger（`/api/v1/docs`）确认服务正常。

**Q：提示未登录无法打开任务中心？**  
- 重新登录；确认 Token 未过期。  
- 若使用 Web，确认与 API **同域或已配置 CORS**。

### 10.2 AI 生成

**Q：点击生成没有反应或立刻失败？**  
- 到 **设置 → 模型厂商** 确认已配置对应供应商与 API Key。  
- 查看任务中心失败原因（常见：`llm_not_configured`）。  
- 云端 Free 档可能触发 **日配额 / 并发** 限制，请次日再试或联系管理员升级。

**Q：生成很慢？**  
- 视频与批量图片属于长时任务，请在任务托盘等待。  
- 避免同时发起过多并发任务。

### 10.3 小说抓取

**Q：链接抓取失败？**  
- 确认是否需要 **站点认证**；桌面端用「应用内登录」获取 Cookie。  
- 部分站点反爬严格，可改用 **文件导入** 或 **粘贴**。

### 10.4 协作与数据

**Q：顶部出现冲突提示？**  
- 表示他人或另一窗口已修改同一资源；按提示 **刷新** 或合并后再保存。

**Q：找不到刚创建的项目？**  
- 确认当前 **工作区** 是否选对。  
- 使用全局搜索按项目名称查找。

### 10.5 导出与发布

**Q：提示「暂不可导出成片」？**  
- 在交付步查看 **评审预览集** 与 **导出预检**，补齐未就绪镜头。  
- 打开任务中心处理失败的视频/导出任务。

**Q：发布按钮灰色？**  
- 在 **平台配置** 中完成渠道连接。  
- 先完成质检 Tab 要求的检查项（若已启用质量门）。

## 11. 术语表

| 术语 | 含义 |
|------|------|
| **工作室 / Studio** | 单项目内的六步创作工作区 |
| **六步** | 剧本 → 美术 → 资产 → 分镜 → 视频 → 成片 |
| **Agent** | 右侧 AI 对话工作区，可调用工具改写剧本、拆镜等 |
| **任务 / Job** | 后端异步执行的长时操作（生成图、视频、导出等） |
| **候选** | 同一镜头或资产的多个 AI 生成结果，需挑选确认 |
| **装配** | 将分镜镜头与资产合成为可导出成片的过程 |
| **质量门** | 发布前自动或人工的质量检查规则 |
| **工作区** | 数据与权限隔离单位（个人或企业） |
