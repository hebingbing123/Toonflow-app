# 快速开始指南

欢迎来到 OpenFlow！根据你的角色选择相应的快速开始指南。

> **产品形态**：OpenFlow 为**闭源云端 SaaS**，终端用户须**注册并登录**后使用；本仓库文档主要服务**已授权**的研发、运维与产品团队。

## 👥 按角色选择

### 🧑‍💻 [开发者快速开始](./for-developers.md)

**适合**：软件工程师、全栈开发者、前端/后端开发者

**内容包括**：
- 开发环境设置
- 项目结构介绍
- 开发工作流
- 测试和调试
- 代码提交规范
- 常用命令和工具

**预计时间**：1-2 小时

[开始阅读 →](./for-developers.md)

---

### 🔧 [运维人员快速开始](./for-operators.md)

**适合**：SRE、DevOps 工程师、系统管理员

**内容包括**：
- 系统架构概览
- 访问权限获取
- 运维手册 (Runbooks)
- 紧急响应流程
- 监控和告警
- 日常运维任务
- 安全最佳实践

**预计时间**：2-3 小时

[开始阅读 →](./for-operators.md)

---

### 📱 创作者 / 制片 / 运营（平台用户）

**适合**：编剧、导演、制片、审片、运营

**使用方式**：在官方客户端 **注册 → 登录 → 进入 Workspace**，无需克隆本仓库。

**内容包括**：
- [OpenFlow 用户操作手册](../product/user-manual.md)（Studio 六步全链路）
- [短视频剪辑用户指南](../features/short-video/user-guide.md)（交付与分发补充）

**预计阅读时间**：约 45–60 分钟（可随用随查）

## 🗺️ 学习路径

### 第一天

1. **选择你的角色指南**并完成阅读
2. **设置开发/运维环境**
3. **浏览项目结构**
4. **加入团队沟通渠道**

### 第一周

1. **深入阅读核心文档**
   - [主路线图](../roadmaps/master-roadmap.md)
   - [架构决策记录](../architecture/adr/README.md)
   - [功能文档](../features/)

2. **熟悉工作流程**
   - Git 工作流
   - 代码审查流程
   - 部署流程

3. **完成第一个任务**
   - 开发者：修复一个 "good first issue"
   - 运维：完成一次模拟演练

### 第一个月

1. **深入了解系统**
   - 阅读所有相关文档
   - 参与团队会议
   - 了解业务逻辑

2. **贡献文档**
   - 更新过时的文档
   - 创建新的文档
   - 分享学习心得

3. **独立工作**
   - 独立完成任务
   - 参与代码审查
   - 帮助新成员

## ❓ 常见问题

### 如何获取访问权限？

联系你的团队负责人或 HR，他们会帮助你获取所需的权限。

### 遇到问题怎么办？

1. 首先查看相关文档
2. 在 Slack 相应频道提问
3. 创建 GitHub Issue
4. 联系团队成员

### 如何贡献文档？

1. 阅读 [文档贡献指南](../CONTRIBUTING.md)
2. 使用 [文档模板](../templates/)
3. 提交 Pull Request
4. 等待审核

### 如何报告 Bug？

1. 在 GitHub 创建 Issue
2. 使用 Bug 模板
3. 提供详细的复现步骤
4. 附上相关日志和截图
